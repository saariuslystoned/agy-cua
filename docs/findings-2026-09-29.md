# Antigravity + Cua Driver interop findings (2026-09-29)

Setup: macOS 26.5.2 arm64, Antigravity CLI 1.2.9 to 1.2.13, `gemini-3.8-flash-high`,
cua-driver 0.30.4 (notarized `CuaDriver.app`, TCC granted to `com.trycua.driver`).

## How Antigravity consumes an MCP server

- `agy` loads a workspace's `.agents/mcp_config.json` and `.agents/skills/`.
  `agy mcp list` shows only the global servers.
- A plugin directory contributes MCP servers through `mcp_config.json` at its
  root. `agy plugin validate` ignores `mcpServers` in `plugin.json` and a
  root `.mcp.json`.
- The model calls every MCP tool through one `call_mcp_tool` meta-tool
  (`ServerName`, `ToolName`, `Arguments`). The agent reads each tool's schema
  from `~/.gemini/antigravity-cli/mcp/<server>/<tool>.json` with `view_file`.
- Large text or image results are saved under
  `~/.gemini/antigravity-cli/brain/<conversation>/.system_generated/steps/<n>/`,
  and the model reads them with `view_file`. The stream-json `output` field is
  `null` for those steps.
- Only text content reaches the model; `structuredContent` does not.

## Consequences for cua-driver

- `snapshot_id` and `element_token` exist only in `structuredContent`, so
  element clicks are refused with `snapshot_id_required`
  ([trycua/cua#4346](https://github.com/trycua/cua/issues/4346)).
- Pixel clicks work, and cua-driver hit-tests each one to an accessibility
  press. But Gemini's pixel estimates were sometimes 40 to 50 px off, which
  caused one failed qualification (63 calls, timeout).
- With `snapshot_id` copied into the text (`bin/agy-cua-mcp`), the agent
  clicks by element: 3 of 3 runs passed in 87 to 117 s with 15 to 18 tool calls,
  zero errors, and Calculator never frontmost.

## Agent behavior worth guarding against

- If told not to read files, the agent can't see offloaded results and starts
  probing tool schemas with placeholder arguments.
- Left unguided, it reached for `get_desktop_state` (a full-desktop capture)
  and unfiltered `list_windows` (200+ windows). The skill forbids both unless
  the user asks.
